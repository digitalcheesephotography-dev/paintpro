🖨️ PaintPro Print Hub

Lets the app send bids straight to your home printer
⬇ Download print_hub.py
1
Download Python (free) from python.org if you don't have it.
During install, check "Add Python to PATH".
2
Open Command Prompt (search "cmd" in Start menu) and run:
pip install requests
3
In the same Command Prompt window, run:
python print_hub.py
You'll see Listening on ntfy.sh/… — leave it running.
4
Auto-start on boot (optional): Press Win+R, type shell:startup, press Enter. Create a shortcut to:
pythonw C:\path\to\print_hub.py
The file is already configured with your private topic — no editing needed. Just download, install, and run.
